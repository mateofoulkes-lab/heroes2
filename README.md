# Heroes II Web Gauntlet

Clon privado jugable en navegador inspirado en Heroes of Might and Magic II.

## Jugar localmente

```bash
npm start
```

Despues abrir `http://127.0.0.1:4173`.

## Que incluye

- Mapa de aventura por turnos con tiles del overworld original.
- Heroe movible por click o teclado.
- Recursos, minas, cofres, artefactos y stacks neutrales.
- Castillo Knight con reclutamiento.
- Batalla tactica simple con sprites reales limpiados a transparencia.
- Prompt de trabajo tipo gauntlet loop en `docs/GAUNTLET_LOOP_PROMPT.md`.

## Controles

- Click en una casilla cercana para moverse.
- Flechas o WASD para mover al heroe.
- Click en Castillo para reclutar.
- En batalla, click en un enemigo para atacar.
- Fin del dia reinicia movimiento y produce recursos de minas capturadas.
